# Sing A Song

React + Vite 기반 모바일 웹 보컬 피치 게임 MVP입니다. 사용자가 앱 내부에서 직접 생성한 짧은 반주를 들으며 목표 음정을 따라 부르면, 마이크 입력만 분석해 목표 음정과 비교하고 `PERFECT`, `GOOD`, `OK`, `MISS` 판정과 점수, 콤보를 표시합니다.

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 표시하는 localhost 주소를 브라우저에서 열면 됩니다.

## 모바일 테스트 방법

1. 모바일 브라우저에서 Vite dev server 주소에 접속합니다.
2. `게임 시작`을 누르고 마이크 권한을 허용합니다.
3. 스피커로 재생되는 간단한 신스 반주에 맞춰 화면의 목표 음정을 따라 부릅니다.
4. 중앙의 목표 음정, 마이크 커서, 판정 텍스트, 점수와 콤보를 확인합니다.

모바일 기기에서 마이크 권한은 HTTPS 또는 localhost 같은 보안 컨텍스트에서 동작합니다. 같은 네트워크의 다른 기기에서 접속할 때는 HTTPS 배포 환경을 사용하는 것이 가장 안정적입니다.

## 오디오 정책

- 유튜브 연동은 포함하지 않습니다.
- mp3, 외부 음원, 사람 보컬이 들어간 원곡을 사용하지 않습니다.
- 반주는 Tone.js Synth로 앱 내부에서 직접 생성합니다.
- 목표 음정 데이터는 [src/data/songs.js](./src/data/songs.js)의 배열로 관리합니다.
- 앱은 오직 사용자의 마이크 입력만 분석해 목표 음정과 비교합니다.

## 곡 데이터

첫 연습곡은 15초 내외의 짧은 멜로디이며, 각 노트는 다음 구조를 사용합니다.

```js
{
  note: 'C4',
  startMs: 0,
  durationMs: 800,
  lyric: 'La',
}
```

새 곡은 `src/data/songs.js`에 같은 구조로 추가할 수 있습니다.
